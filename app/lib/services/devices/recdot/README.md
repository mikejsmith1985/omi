# viaim RecDot protocol package

Pure, transport-free pieces for talking to viaim RecDot earbuds. Nothing here touches
Bluetooth, the accessory framework, or Omi's connection state; those live in
`../connectors/viaim_recdot_connection.dart` and `../transports/recdot_link_transport.dart`.

| File | Owns |
|---|---|
| `starot_codec.dart` | v2 frame encode/decode and the byte-stream reassembler, TLV attribute groups, the two-channel call-audio split, FlashRecord chunk parsing, the download request, and the BLE advertisement layout |
| `recdot_commands.dart` | Opcode constants and typed request builders / response parsers for the commands the connector sends |
| `recdot_flash_sync.dart` | The FlashRecord transfer state machine, whose "delete on the bud" step is only reachable after Omi has durably stored the audio |

The wire facts are recorded in the TranscriptBoss repository under
`specs/002-viaim-recdot-device/protocol.md`; every layout here is checked byte-for-byte
against golden vectors generated by an independent Python implementation
(`test/fixtures/recdot_golden/`). Audio decoding is separate: `lib/utils/audio/g722_decoder.dart`.
